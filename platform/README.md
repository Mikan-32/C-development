# platform/ — プラットフォーム層

OS 固有の処理だけを置く場所です（[ADR-0001](../docs/adr/0001-c-core-and-kotlin-platform-layer.md)）。

| フォルダ | 中身 |
|---|---|
| `include/` | C から見える唯一の窓口 `nk_platform.h`。アプリ本体はこのヘッダーだけを使う |
| `android/` | Android 版の実装（Kotlin ＋ JNI）。JNI の処理はこの中に閉じ込める |
| `pc/` | PC 版の代役（スタブ）。Kotlin に触らないメンバーも、PC 上でアプリ全体を動かせるようにする |

## Android 版が担当すること

- アラームの登録（AlarmManager）と、時刻が来たことを C に伝えること
- 夜間計測の常駐（フォアグラウンドサービス）
- 通知（全画面通知を含む）
- 端末の再起動後に、アラームを登録し直すこと
- 権限の要求（マイク、通知、正確なアラームなど）
- データベースの暗号化キーを Android Keystore で守ること

## PC 版の代役がすること（例）

- アラームの登録 → ログに出力し、指定した時間が来たら（または早送りで）コールバックを呼ぶ
- 夜間計測の常駐 → 何もしない（PC では不要）
- 暗号化キー → 開発用の固定キーを返す

## 守ること

- ここには判断やロジックを書きません。判断は C 側（`src/`）で行います。
- `nk_platform.h` を変えるときは、Android 版と PC 版の両方を同じ PR で直します。
