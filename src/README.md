# src/ — アプリ本体（C）

コンポーネントごとにフォルダを分けています。各コンポーネントの責務は、[アーキテクチャ設計書](../docs/architecture/nemunoki-architecture-c4.pdf)の 5 章と対応しています。

| フォルダ | コンポーネント | 責務 | PRD |
|---|---|---|---|
| `app/` | アプリの入口 | `main` と、各コンポーネントの組み立て | — |
| `common/` | 共通 | エラー型 `nk_result` など、全体で使う型と小さな部品 | — |
| `ui/` | 画面 | 各画面の表示と操作（LVGL）。取得中・失敗・データ不足の状態を必ず表示する | 4.3, 5.1, 5.3 |
| `session/` | 睡眠セッション管理 | 就寝から起床までの状態管理、計測の開始と停止、取得できなかった時間の記録。同意が済んでいなければ計測を始めない | 4.1, 5.2 |
| `sensing/` | 計測処理 | マイクと加速度センサーの信号から、いびきと体動のイベントを検出する。保存はしない | 4.1 |
| `analysis/` | 分析・スコア | 睡眠段階の推定とスコアの算出。データ不足の理由と結果の確からしさも返す | 4.2, 4.3 |
| `feedback/` | フィードバック生成 | 習慣やカーテン設定の提案文を作る。「責めない・断定しない」表現のルールをここに集約する | 4.2, 5.1 |
| `data/` | データアクセス | 睡眠ログ、設定、同意状態の読み書きと、全データの削除（SQLCipher） | 4.1, 5.2 |
| `curtain/` | カーテン制御 | 手動の開閉と、開閉時刻の予約。実行結果を確認してから成功と表示する | 4.4, 5.3 |
| `curtain_api/` | カーテン API 接続 | メーカーのクラウド API との HTTPS 通信（libcurl・cJSON） | 4.4, 5.2 |
| `automode/` | 自動モード | 有効・無効の管理（初期値は無効）と、条件に応じたカーテン予約とアラーム設定 | 4.5 |
| `alarm/` | アラーム | 鳴動画面とスヌーズの判断。OS への登録はプラットフォーム層に頼む | 4.7 |
| `sound/` | 入眠サウンド | 同梱した音源の再生、停止、音量調整（SDL3） | 4.6 |

## ルール

- 各フォルダには、公開ヘッダー（例：`session.h`）と実装（`session.c`）を 1 対 1 で置きます。
- 各コンポーネントは静的ライブラリ `nk_<フォルダ名>` として CMake に登録し、`nk_options` をリンクします。
- 依存の向きや名前の付け方などは [CONTRIBUTING.md](../CONTRIBUTING.md) の「C のコーディング規約」に従います。

`.gitkeep` は空のフォルダを Git に残すためのファイルです。最初のファイルを置いたら削除してください。
