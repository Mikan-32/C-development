# 0001. アプリ本体は C、OS 固有の処理は Kotlin のプラットフォーム層に置く

- 状態：承認
- 日付：2026-10-27

## 背景

- チームのルールで、アプリを書く言語は C だけと決まっている。ただし、ライブラリの内部はどの言語で書いてもよい。
- PRD のアラーム（4.7）、夜間の計測（4.1）、通知は、OS の仕組みを使わないと実現できない。Android では、これらの多くが Java・Kotlin の API でしか使えない。
- C だけでは、PRD のリリース時の受け入れ条件を満たせない。

## 決定

- アプリ本体（画面、計測、分析、機器操作）はすべて C で書く。
- OS 固有の処理だけを、自作のプラットフォーム層ライブラリ（Kotlin ＋ JNI）に置く。
- C から見えるプラットフォーム層の窓口は、C のヘッダー 1 枚（`platform/include/nk_platform.h`）にまとめる。
- この運用がチームのルール上問題ないことは確認済み。

## 結果

- PRD の機能を満たせる。
- OS に依存しない部分は、PC 上でビルドしてテストできる。
- Kotlin を書けるメンバーが必要になる。
- プラットフォーム層にロジックが入り込まないよう、レビューで確認する必要がある（CODEOWNERS で担当者を決める）。
