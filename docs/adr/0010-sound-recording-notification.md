# 0010. 入眠サウンドの音源、録音の扱い、通知とスヌーズ

- 状態：提案
- 日付：2026-10-31
- 対応タスク：全員タスク 5「音声・通知の決定」
- 画面：[UX-6](../ux/UX-6_sound-alarm.md)

## 背景

- PRD 4.6 は環境音とリラクゼーション音楽の再生、4.7 はアラームとスヌーズ、5.2 は録音の有無・保存範囲・保存期間の明示を求めている。
- C4 設計書では「音源は同梱、いびきの録音は保存せず検出結果だけを残す」と仮置きしていた。

## 決定

### 音源
| 種類 | 入手方法 | 形式 |
|---|---|---|
| ホワイト・ピンク・ブラウンノイズ | **C で生成する**（ファイル不要、ライセンス不要） | — |
| 雨・波・川などの環境音 | 再配布できるライセンス（CC0 など）の素材か、メンバーが自分で録音したもの | 30〜60 秒の継ぎ目のないループ。Ogg Vorbis |
| リラクゼーション音楽 | メンバーの自作か、アプリへの同梱が許されている素材 | 同上 |

- 素材ごとに出典とライセンスを `assets/sounds/LICENSES.md` に記録する。条件が確認できない素材は入れない。
- Ogg の読み込みには stb_vorbis（パブリックドメイン、単一ファイル）を使う案とする（`third_party/` への追加は別 PR で合意）。
- 再生は SDL3 の `SDL_AudioStream`。音量はアプリ内のスライダー、タイマー（15・30・60 分・朝まで）の終わりは 10 秒でフェードアウトする。

### 録音
- 既定：**録音は保存しない**。マイクの音は端末内で特徴（音の大きさ、いびきらしさ）に変換し、元の音はすぐ捨てる。
- 任意：設定で「いびきの録音を残す」をオンにした人だけ、いびきが続いた場面を **1 回 10 秒、1 晩 10 件まで** 暗号化して保存し、**7 日で自動削除**する。オンにする画面で、同室の人の声が入る可能性があることを説明する。
- 計測中は Android のマイク使用中の表示が出ることを、初回設定で説明する。

### 通知
| チャネル | 重要度 | 用途 |
|---|---|---|
| 計測中 | 低 | 夜間サービスの常駐表示（「止める」ボタン付き） |
| アラーム | 高 | 鳴動。アラーム用の音、繰り返し、ロック中は全画面 |
| カーテン・自動モード | 中 | 失敗・未確認の知らせ、自動モードの一時停止 |
| おやすみの通知 | 中 | 就寝時刻のお知らせ（任意、初期値はオフ） |

### アラームとスヌーズ
- 音は同梱のアラーム音 3 種類から選ぶ。音量は端末のアラーム音量に従う。
- スヌーズ：初期値 5 分（5・10・15 分から選択）、最大 3 回（0〜5 回で変更可）。残り回数を鳴動画面に表示する。
- 10 分間操作がなければ鳴動を止め、「アラームを止めました」と通知する。
- 鳴動中に「止める」を押すと、起床として計測を終える。

## 結果

- ノイズを生成にすると、ライセンスの心配がない音源を最初から用意できる。
- 録音を既定で保存しないので、PRD 5.2 の説明が短く明確になる。
- アラーム音を通知の音として鳴らすので（platform-boundary.md の 4 章）、徐々に大きくする演出はできない。必要なら v2 で検討する。
