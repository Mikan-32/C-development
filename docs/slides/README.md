## 発表までにやること（CS-11）

- 表紙にチーム名・氏名・日付を入れる
- 課題のスライドに統計を入れる場合は、出典を確認して書く
- 画面の画像（UI モック v2）を、LVGL の実画面（PC 版のスクリーンショット）に差し替える
- 検証結果を、実データでの結果（AI-7 の第 2 段）に更新する
- フォントは游ゴシック（Yu Gothic）です。ほかの PC で開くと崩れる場合は、PDF にして持っていく
