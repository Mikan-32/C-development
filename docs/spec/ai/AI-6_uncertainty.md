# AI-6 不確かな結果を抑える

- 状態：提案
- 使う人：`analysis/`（確からしさを返す）、`feedback/`（文を選ぶ）、`ui/`（表示を変える）
- PRD：4.2「データ不足などで分析できない場合はその理由を表示し、不確かな分析結果は断定的に表示しない」

## 1. 出さない条件

| 対象 | 出さない条件 | 代わりに出すもの |
|---|---|---|
| スコア | 品質 `FAILED`、使えた配点 < 70、または理由 Q07 がある | 理由（AI-2 の理由コード）と次の行動 |
| 睡眠段階 | 品質 `FAILED`、または睡眠時間 0 | 「取得できた時間」の帯だけ |
| 深い・浅いの内訳 | 品質 `INSUFFICIENT` 以下 | 「眠り」と「覚醒」の 2 色だけ |
| いびき・呼吸数 | AI-2 の 2 章の条件を満たさない | 「この夜は記録していません」 |
| 週の傾向 | `OK` の夜が 3 夜未満 | 「あと N 夜で傾向が表示されます」（Q10） |
| 比較のフィードバック（例：サウンドあり・なし） | どちらかの群が 2 夜未満、または差が誤差の範囲（寝つきで 5 分未満など） | 出さない |

## 2. 言い方の段階

確からしさに応じて、文末を変える。`feedback/` と `ui/` はこの表の言い方だけを使う。

| 確からしさ | 使う言い方 | 例 |
|---|---|---|
| 計測した事実（時刻、回数） | 「〜でした」 | 寝ついたのは 0:12 でした |
| 推定（`HIGH`・`MED`） | 「〜と推定されます」「〜のようです」 | 深い眠りは 1 時間 10 分と推定されます |
| 推定（`LOW`） | 「参考値」を添え、数字を控えめに出す | 睡眠時間（参考値）約 5 時間 |
| 傾向（3 夜以上） | 「〜の日は〜の傾向がありました」 | サウンドを使った日は、寝つきが短い傾向がありました |

**使わない言い方**：「〜が原因です」「〜のせいで」「必ず」「確実に」「異常」「危険」。相関を因果として書かない。

## 3. 画面での見せ方

| 状態 | 見せ方 |
|---|---|
| 参考値 | スコアの数字を `--ink-2` の色にし、ラベルの代わりに「参考値」の札を付ける。リングは点線 |
| 段階の確からしさ `LOW` | 段階の帯を薄くし、「深い眠り（参考値）」と書く |
| 欠損 | 段階の帯の該当時間を斜線にし、タップで理由を出す |
| 推定の説明 | 段階の帯の右上に「?」を置き、AI-3 の 6 章の説明文を開く |

## 4. 医療に関わる表現

- 病名・診断名（不眠症、睡眠時無呼吸症候群など）は、アプリの文言に出さない。
- 受診を勧める文は 1 つだけに限り、条件と文言を固定する（AI-5 の FB-12）。不安をあおらない言い方にする。

## 5. テスト観点（AI-7 で確認する）

- 1 章の各条件で、出力が NULL か「出さない」になること
- フィードバックの全文型が、2 章の「使わない言い方」を含まないこと（文言のチェック）
- 推定の文に「推定」「ようです」「傾向」「参考値」のいずれかが入っていること
