# UX-4 履歴

- 状態：提案
- PRD：4.3「複数日の睡眠記録をグラフで比較」「過去の日付を選び、その日の記録を確認（詳細な分析結果を表示）」
- モック：v2 の「LG-01 履歴」「LG-02 日別の詳細」

## 1. LG-01 履歴

| # | 部品 | 内容 | LVGL |
|---|---|---|---|
| 1 | 期間の切り替え | 週／月 | `lv_buttonmatrix`（2 つ） |
| 2 | カレンダー | 月のカレンダー。記録がある日に点（色は品質：`OK` 青紫、`INSUFFICIENT` 灰、`FAILED` 輪郭のみ）。日付をタップで LG-02 | `lv_calendar`（記録日は強調表示の日付として渡す） |
| 3 | まとめの 4 マス | 平均睡眠時間（前の期間との差）、目標達成の夜数、平均の寝た時刻、平均の起きた時刻 | グリッド |
| 4 | 睡眠時間の棒グラフ | 週：7 本、月：週ごとの平均 4〜5 本。目標の点線。選んだ棒だけ値を表示 | `lv_chart`（棒）＋目標線は描画イベントで追加 |
| 5 | 寝た時刻・起きた時刻のリズム | 21:00〜翌 9:00 の縦軸に、寝た時刻から起きた時刻までの縦の帯 | 部品 `nk_rhythm`（描画イベントで角丸の矩形） |
| 6 | 日ごとの一覧 | 日付、睡眠時間の小さな棒、スコア、品質の印。タップで LG-02 | `lv_list` |

- 月の切り替えは左右の矢印（`lv_calendar` の見出し）。未来には進めない。
- `INSUFFICIENT` の夜は棒を薄く、`FAILED` の夜は棒を出さず「×」の印。平均や達成数には `OK` の夜だけを使い、その旨を小さく書く（「分析できた 5 夜の平均」）。

## 2. LG-02 日別の詳細

ホームの内容に、詳しい分析を足した画面。

| # | 部品 | 内容 |
|---|---|---|
| 1 | 見出し | 「10月30日（金）の夜 → 31日（土）の朝」、前日・翌日への矢印 |
| 2 | スコアと内訳 | リング＋項目ごとの点数（AI-4 の 1 章の 5 項目を横棒で）。最も達成率が低い項目に「ここを整えると良さそう」 |
| 3 | 眠りの帯（大） | 時刻の目盛り付き。寝返り・いびき・大きな音・サウンド・カーテン・アラームを帯の上に印で重ねる |
| 4 | 指標の表 | 寝床にいた時間、睡眠時間、寝つき、中途覚醒（回数・合計）、効率、深い眠り（推定）、浅い眠り（推定）、寝返り、いびき、呼吸数。推定の項目には「推定」の札、取れない項目は「記録なし」と理由 |
| 5 | 取得状況 | 計測できた割合、欠損の区間と理由、置き方の確認結果、使ったセンサー |
| 6 | その日のアドバイス | その日に出したアドバイス（AI-5） |
| 7 | 操作 | 「目覚めの気分を記録」（未入力なら）、「この夜の記録を削除」（確認つき） |

## 3. 比較グラフの決まり

- 棒グラフの縦軸は 0〜10 時間で固定し、週・月を切り替えても目盛りを変えない（見比べやすさのため）。
- 色は単一系列（`--series`）。選んだ棒だけ不透明、ほかは 50%。
- グラフの数値はグラフの外（一覧）でも読めるようにする（グラフをタップできない人のため。UX-8）。

## 4. データがないとき

| 状況 | 表示 |
|---|---|
| 記録がまったくない | カレンダーだけ表示し、「最初の記録は、今夜おやすみを始めると作られます」 |
| 選んだ日に記録がない | LG-02 を開かず、カレンダーの下に「この日の記録はありません」 |
| 週に `OK` の夜が 3 夜未満 | まとめの平均を出さず「あと N 夜で平均が表示されます」（Q10） |
