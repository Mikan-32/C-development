# ねむのき UIモック v1 — 設計メモ

作成日: 2026-10-16 ／ 成果物: `claude/nemunoki-mock-v1.html`（単一HTML・外部依存なし。ブラウザで開くだけで動作）

## 画面構成（スマホ 390×844・下タブ4つ）

| タブ | 内容 | 動くもの |
|---|---|---|
| ホーム | 挨拶／睡眠スコア（リング）／昨夜の睡眠時間・就寝起床／寝つき・中途覚醒・目覚め／今日のひとことアドバイス／今週の睡眠時間ミニグラフ／「睡眠を記録する」CTA | 各リンクから記録・アドバイス・履歴へ遷移 |
| 記録 | 就寝・起床時刻（±10分ステッパー、睡眠時間を自動計算）／寝つき（3段階チップ）／中途覚醒（0〜3回以上）／目覚めの気分（5段階の顔）／昨日の習慣（カフェイン・お酒・運動・寝る前スマホ・昼寝）／メモ | 「記録する」でデータ更新 → トースト → ホームへ。ホーム・アドバイス・履歴の数値が連動 |
| アドバイス | 今週のまとめ（平均睡眠・平均就寝・就寝のばらつき）／優先度付きアドバイス4件（アコーディオン：「あなたの記録から」の根拠＋「今夜からできること」）／医療免責の注記 | 開閉。文中の数値は記録から算出（休日と平日の就寝差、スマホ有無の寝つき差、カフェイン有無の中途覚醒差） |
| 履歴 | 週／月切替／統計タイル4つ／睡眠時間の棒グラフ（目標線つき）／就寝と起床のリズム（21:00→9:00のフローティングバー）／日別（週別）の一覧 | 棒をタップで日（週）を選択、選択行の詳細を表示。月は直近4週の週平均 |

ビューワー側（アプリ外）には画面切替チップと「1画面／4画面を並べる」切替あり。幅480px以下では端末実機風にフル表示。

## デザイントークン

- 背景 `#0E1330`／カード `#1A2147`／一段上 `#232B5A`／罫線 `rgba(255,255,255,.08)`
- 文字: 主 `#F2F3FA`・副 `#B8BCD8`・補助 `#9298C2`（カード上で 4.8:1 以上を確認）
- ブランド（CTA・リンク・選択）: ネムノキの花をイメージしたピンク `#F08CA8`（濃 `#E36F91`）
- グラフ系列: ラベンダー `#7788EE`（ダーク面での明度帯・コントラストを検証済み、単一系列のみ使用）
- ステータス: 良 `#5FD3A8`／注意 `#F2C26B`／要改善 `#F09A6A`（スコアリング・優先度バッジのみに使用）
- フォント: システム日本語サンス（Hiragino Sans / Noto Sans JP など）、`palt` 有効
- 角丸 20px（カード）／14px（タイル）、棒グラフは幅≤22px・上端4px丸

## サンプルデータと計算ロジック（モック用の仮置き）

- 1週間分（10/10〜10/16、起床日で管理）。各日: 就寝・起床（分）、寝つき（分）、中途覚醒回数、気分1〜5、習慣、メモ
- 目標睡眠時間 7時間30分（固定）
- スコア = 睡眠時間（目標比・60点）＋寝つき（15点）＋中途覚醒（15点）＋目覚めの気分（10点）。85以上「とても良い」／70「良い」／55「まずまず」／未満「要改善」
- 今日のアドバイスの就寝目安 = 今朝の起床時刻 − 目標睡眠時間

## リリース前に判断・修正が必要な点（フラグ）

1. 挨拶の名前（遥陽さん）と日付（10/16）がサンプル固定。外部共有前に汎用のダミーへ差し替える
2. スコア計算式・しきい値は仮置き。プロダクトとして根拠のある定義に置き換える
3. アドバイス本文に健康に関する記述（カフェインの持続時間、朝の光など）を含む。睡眠の専門知見でレビューし、免責文の文言も確認する
4. 未実装の導線: 期間の‹ ›送り、プロフィール、設定（目標時間・おやすみ通知）、オンボーディング／ログイン
5. 記録画面は「昨夜」のみ対象。過去日の編集や日付選択、10分刻みステッパー以外の時刻入力UIが必要
6. ダークテーマのみ。ライトテーマ／OS設定追従は未対応
7. アクセシビリティ: グラフのタップ領域はキーボード非対応（一覧表で代替）、SVG内の文字が9.5〜11pxと小さい、文字サイズ拡大（Dynamic Type）未検証
8. 履歴「月」の過去3週分は固定値、期間表示（9/19–10/16）も固定
9. モダンブラウザ前提（`dvh`、`backdrop-filter`、`replaceChildren` 等）。古いブラウザでは崩れる可能性
