# UX-6 入眠サポートとアラーム

- 状態：提案
- PRD：4.6（音源の選択、再生・停止、音量）、4.7（アラーム、スヌーズ）
- 決定：ADR-0010
- モック：v2 の「NT-01 おやすみ」「NT-02 計測中」「NT-03 アラーム鳴動」

## 1. NT-01 おやすみ

| # | 部品 | 内容 |
|---|---|---|
| 1 | 今夜の確認 | 電池残量と充電中か（20% 未満で充電していなければ注意）、マイクの許可、置き方のひとこと |
| 2 | サウンド | 2 列のカード（ホワイトノイズ、ピンクノイズ、ブラウンノイズ、雨、波、川、音楽）。タップで試聴（再生中のカードに波形の印） |
| 3 | 再生の操作 | 再生・停止の大きなボタン、音量のスライダー、タイマー（15 分・30 分・60 分・朝まで） |
| 4 | アラーム | 起きる時刻（大きな数字。タップで `lv_roller`）、オン・オフ、スヌーズ（5 分・最大 3 回）の要約。自動モード中は「自動モードで 6:30 にセット済み」 |
| 5 | 主ボタン | 「計測をはじめる」（サウンドを選んでいればサウンドも続ける） |

- **最小の操作**：前回の設定を覚えておき、開いて主ボタンを押すだけで始められるようにする。
- 計測を始めると夜間サービス（Kotlin）が動き、NT-02 に移る。自動モード中はカーテンを閉める。

## 2. NT-02 計測中

暗い画面。画面の明るさを抑えるため、文字は `--night-ink`（UX-8）。

| # | 部品 | 内容 |
|---|---|---|
| 1 | 時計 | 大きな時刻 |
| 2 | 計測の状態 | 「計測中・2 時間 10 分」。止まったら「計測が止まっています」と理由（UX-7） |
| 3 | サウンドの小さな操作 | 再生中の音源、停止、音量 |
| 4 | アラーム | 「6:30 に起こします」 |
| 5 | 起きた | 「起きた」（長押し 1 秒）→ NT-04 |

- 既定では 30 秒操作がなければ画面を消す（端末の設定に任せる）。設定で「時計を表示したままにする」を選んだ人だけ `SDL_DisableScreenSaver`。
- 誤って止めないよう、「起きた」「計測を止める」は長押し。戻るボタンでは閉じない（UX-2 の 4 章）。

## 3. NT-03 アラーム鳴動

| # | 部品 | 内容 |
|---|---|---|
| 1 | 時刻 | とても大きく |
| 2 | 止める | 画面の下半分を占める大きなボタン（1 タップ。寝ぼけていても押せるよう、スライド操作にはしない） |
| 3 | スヌーズ | 「5 分後にもう一度（あと 2 回）」。残り 0 回なら表示しない |
| 4 | カーテン | 自動モード中：「カーテンを開けています」→ 結果（UX-5 の 4 状態） |

- 音は通知チャネルで鳴っている（platform-boundary.md の 4 章）。「止める」「スヌーズ」は `alarm/` が判断し、`nk_platform_alarm_ringing_stop` で音を止める。
- スヌーズを押すと次の鳴動を予約し、画面に「6:35 にもう一度鳴ります」を出してから閉じる。
- ロック中で全画面通知の許可がない場合は、通知のボタン（スヌーズ・止める）からも同じ操作ができる。

## 4. アラームの設定画面（NT-01 の 4 から開く）

| 項目 | 選択肢 | 既定 |
|---|---|---|
| 起きる時刻 | 平日・休日で別にできる | 平日 6:30、休日 オフ |
| 音 | 同梱の 3 種類（試聴可） | 1 番目 |
| スヌーズの長さ | 5・10・15 分 | 5 分 |
| スヌーズの回数 | 0〜5 回 | 3 回 |
| バイブレーション | オン・オフ | オン |

正確なアラームの許可がないときは、この画面の上に警告と「設定を開く」を出す（UX-7 の ST-PERM-EXACT-ALARM）。

## 5. LVGL での作り方

- サウンドのカードは `lv_obj` のグリッド。再生中の印は `lv_anim` で 3 本の棒を上下させる（動きを減らす設定では止める）。
- 音量は `lv_slider`。値は `SDL_SetAudioStreamGain` にそのまま渡す（`sound/`）。
- NT-02 と NT-03 は、タブバーを隠した全画面の画面にする。
