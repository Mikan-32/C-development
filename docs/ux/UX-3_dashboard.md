## 2. 表示の決まり

- 開いたらまず **DB に保存済みの最新の結果** を表示する（PRD 5.3）。分析中なら前回の結果を薄く表示し、帯で「分析しています」と出す。
- スコアの色は AI-4 の 2 章。「参考値」のときはリングを点線にし、数字を `--ink-2` にする。
- 推定値には AI-6 の言い方を使う（例：「深い眠り 1 時間 10 分（推定）」）。
- 数値の横に単位を付け、時刻は 24 時間表記（「0:12」）にする。
- 前日との差、週の平均などの比較は、品質 `OK` の夜どうしだけで行う。

## 3. 朝の流れ（NT-04 → HM-01）

1. アラームを止める、または「起きた」を押す → NT-04「おはようございます。計測を終えました」
2. 保存（1〜2 秒）→ 分析（数秒）の進み具合を表示（ST-SAVING → ST-ANALYZING）
3. 任意：「今朝の目覚めは？」（すっきり／ふつう／ねむい）の 1 タップ。飛ばせる。設定で非表示にできる
4. ホームへ。スコアのリングだけ 0.6 秒で伸ばす（ここだけ動きを付ける。動きを減らす設定がオンなら付けない）

## 4. 状態ごとのホーム

| 状態 | スコアのカード | 眠りの帯 | アドバイス |
|---|---|---|---|
| 初めて（記録なし） | 「今夜から記録できます」＋「おやすみを始める」 | 出さない | 「置き方のコツ」 |
| 分析中 | 前回の結果を薄く＋帯 | 前回 | 前回 |
| `OK` | 通常 | 通常 | 通常 |
| `INSUFFICIENT` | 「参考値」 | 浅い・深いを分けず 2 色 | 該当すれば FB-13 |
| `FAILED` | 理由と次の行動（AI-2 の 3 章） | 取得できた時間の帯だけ | 前回の続き |
| 昨夜は計測なし | 「昨夜の記録はありません」＋直近の記録の日付 | 出さない | 前回の続き |
