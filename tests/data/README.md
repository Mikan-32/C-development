# tests/data/ — 回帰テスト用のデータ

計測アルゴリズム（いびき・体動の検出）を変えたときに、結果が意図せず変わっていないかを確かめるためのデータを置きます。

## ルール

- `.wav`（録音）と `.csv`（センサーログ）は、`.gitattributes` の設定で自動的に Git LFS に入ります。
- **録音・計測は、本人の同意を得たうえで行います。** 同意を得ていないデータは置きません。
- 名前、会話の内容など、個人を特定できる情報が入らないようにします。
- GitHub の LFS には容量の上限があるので、必要な部分だけを短く切り出して置きます。
- ファイル名は `YYYYMMDD_内容_端末.wav` の形にします（例：`20261101_snore-light_pixel8.wav`）。
- 各データの説明（録った状況、期待する検出結果）を、同じフォルダの `index.md` に書きます。
