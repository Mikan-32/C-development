## 結果の残し方

実施したら、対応する Issue に次の形でコメントします。失敗した項目があれば、バグの Issue を立ててリンクします。

```
### 手順書 TM-01（アラーム）の結果
- 実施日：2026-11-xx
- 端末：Pixel 8 / Android 16（ビルド：コミットのハッシュ）
- 結果：12 項目中 11 項目 OK
- NG：No.7（再起動後に鳴らない）→ #xx
```

## 守ること

- 一晩の計測は、本人の同意のうえで行います。録音を残す設定はオフのまま行います。
- 実機での結果のファイル（ログ、スクリーンショット）に、個人を特定できる情報を入れません。
