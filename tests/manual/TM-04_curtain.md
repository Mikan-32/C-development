# TM-04 カーテンの操作

- 段：5（偽サーバー、PC）と 8（実機：SwitchBot カーテン 3＋ハブ）
- 前提：CS-6（自動モードの項目は CS-7）の実装が入ったビルド
- 関係：ADR-0006、ADR-0009、UX-5 の 2 章、UX-7 の 3 章

## 偽サーバー（段 5）

カーテン API の接続先を設定で偽サーバーに変え、次の応答を返させる。

| No. | 偽サーバーの応答 | 期待する表示 | 結果 |
|---|---|---|---|
| 1 | 成功し、状態が 6 秒後に `moving: false`・目標の位置 | 依頼中（伝えています → 動いています）→ 成功（確認済み） | |
| 2 | HTTP 401 | 失敗：接続の設定を確かめてください | |
| 3 | HTTP 200 で `statusCode` 190 | 失敗：カーテンが応答しません | |
| 4 | 応答なし（20 秒） | 失敗：インターネットにつながりません | |
| 5 | 成功するが、`moving: true` のまま | 45 秒後に未確認 | |
| 6 | 1 回目と 2 回目は失敗、3 回目に成功（自動モードの再試行） | 15 秒後・60 秒後に再試行し、成功（確認済み） | |

## 実機（段 8）

| No. | 操作 | 期待する結果 | 結果 |
|---|---|---|---|
| 7 | BR-02 でトークンとシークレットを貼り付けて接続 | カーテンの一覧に表示され、選べる | |
| 8 | 開ける・閉める・位置 50% | 実際に動き、成功（確認済み）が表示される | |
| 9 | 自動モードを有効にして、アラームを 15 分後に設定 | 5 分後（アラームの 10 分前）に静音で開く | |
| 10 | 自動で開いたあとに手動で閉める | その朝は開け直さない | |
| 11 | 「次の 1 回だけスキップ」→ 翌朝 | 開けない。その次の朝は開ける | |
| 12 | ハブの電源を抜いて「開ける」 | 失敗（カーテンが応答しません）。画面に残る | |
| 13 | 両開き（2 台）の場合 | 1 台への命令で両方が動くかを記録する（ADR-0006 の確認事項） | |

## 注意

- トークンとシークレットを、ログ、スクリーンショット、Issue に載せない。
- API には 1 日の回数の上限がある。テストで連続して呼びすぎない。
