# TM-02 一晩の計測

- 段：7（実機）
- 前提：SP-2 または CS-2 の実装が入ったビルド。本人の同意を得たうえで行う
- 関係：ADR-0005、AI-1、AI-2、ADR-0011 の「実機で必ず確認する範囲」

## 準備

1. 電池を 100% にする。充電する夜としない夜を、それぞれ 1 回以上行う。
2. スマホを枕元のマットレスの上に、画面を上にして置く。
3. 寝る前に、睡眠日誌（AI-7 の 6 章）の用紙を用意する。

## 手順と期待する結果

| No. | 確かめること | 期待する結果 | 結果 |
|---|---|---|---|
| 1 | 計測の開始 | 「計測をはじめる」で計測中の通知が出る。NT-02 が表示される | |
| 2 | 画面オフ | 30 秒後に画面が消え、計測は続く（朝に欠損がない） | |
| 3 | 電池の減り（充電なし） | 8 時間で 20% 以下 | |
| 4 | 発熱 | 朝に触って熱くない（端末の温度の表示があれば 40 ℃未満） | |
| 5 | 記録の量 | 約 960 エポック（8 時間）。`acc_cov` が 0.8 以上のエポックが 95% 以上 | |
| 6 | わざと止める：夜中にデバッグ版のプロセスを `adb shell run-as <パッケージ名> kill <PID>` で止め、朝に開く（「強制停止」はアラームの登録も消えるので使わない） | 止まった時刻からの欠損が Q04 として表示される | |
| 7 | 起床 | アラームで起きる、または「起きた」を長押し | 保存中 → 分析中 → ホームにスコアが出る（30 秒以内） | |
| 8 | 日誌との比較 | 日誌の寝た時刻・起きた時刻と比べる | 差を記録する（合格の基準は AI-7 の 6 章） | |

## 記録すること

端末名、Android の版、充電の有無、電池の減り（%）、発熱、計測できた割合、日誌との差（寝つき・睡眠時間）、気づいたこと。
