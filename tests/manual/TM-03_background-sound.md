# TM-03 画面オフでの入眠サウンド

- 段：7（実機）
- 前提：SP-2 または CS-8 の実装が入ったビルド
- 関係：ADR-0004（SDL3 のヒント 2 つ）、ADR-0010、platform-boundary.md の 4 章

## 手順と期待する結果

| No. | 状況 | 操作 | 期待する結果 | 結果 |
|---|---|---|---|---|
| 1 | 再生 | NT-01 で「雨」を選んで再生 | 音が鳴る。音量のスライダーで大きさが変わる | |
| 2 | 画面オフ | 再生中に電源ボタンで画面を消す | 音が止まらない（5 分以上） | |
| 3 | 別のアプリ | 再生中にホームボタンでほかのアプリを開く | 音が止まらない | |
| 4 | 計測と同時 | 再生したまま「計測をはじめる」 | 音が続き、計測も続く。いびきとして記録されない（`NK_EPF_SOUND_ON`） | |
| 5 | タイマー | タイマー 15 分で再生し、画面を消す | 15 分後に 10 秒かけて小さくなり、止まる | |
| 6 | 生成ノイズ | ホワイト・ピンク・ブラウンノイズを順に再生 | 途切れや周期的な音の継ぎ目がない | |
| 7 | ループ | 雨（ループ素材）を 3 分再生 | 継ぎ目で音が途切れない | |
| 8 | 電話 | 再生中に電話を受ける | 音が止まり、通話が終わったら再開する（または停止のまま、どちらかに決めて記録する） | |

No.2 または No.3 で音が止まる場合は、ADR-0004 の「結果」に書いた代わりの案（入眠サウンドの出力だけを AAudio にする）を検討する Issue を立てる。
