# TM-01 アラームの確実性

- 段：6（エミュレーター）と 7（実機）
- 前提：アラームの試作（SP-1）または CS-8 の実装が入ったビルド。正確なアラームの許可と通知の許可はオン（No.9・10 を除く）
- 関係：platform-boundary.md の 4 章、ADR-0010、UX-6 の 3 章

## 準備

```powershell
adb devices                                  # 端末がつながっているか
adb shell dumpsys alarm | Select-String nemunoki   # 登録済みのアラームを確認（PowerShell）
```

各項目では、アラームを「今から 3 分後」に設定してから操作する。

## 手順

| No. | 状況 | 操作 | 期待する結果 | 結果 |
|---|---|---|---|---|
| 1 | アプリを前面に表示 | そのまま待つ | 時刻に鳴り、NT-03 が表示される | |
| 2 | 画面ロック中 | 電源ボタンで画面を消して待つ | 画面が点き、ロック画面の上に NT-03 が出る。音が鳴る | |
| 3 | 別のアプリを使用中 | ブラウザを開いて待つ | 上部に通知が出て、音が鳴る。通知のボタンでスヌーズ・停止できる | |
| 4 | アプリを終了 | 最近使ったアプリの一覧から上にスワイプして待つ | No.2 と同じ | |
| 5 | 再起動 | アラームを 10 分後に設定 → 端末を再起動 → ロックを解除せずに待つ | 時刻に鳴る（再起動後の再登録） | |
| 6 | Doze 中（エミュレーター） | `adb shell dumpsys deviceidle force-idle` の後に待つ | 時刻に鳴る。終わったら `adb shell dumpsys deviceidle unforce` | |
| 7 | スヌーズ | 鳴ったらスヌーズ | 5 分後に再び鳴る。鳴動画面に「あと 2 回」 | |
| 8 | スヌーズの上限 | 3 回スヌーズする | 4 回目の鳴動でスヌーズのボタンが出ない | |
| 9 | 全画面通知の許可がオフ | 設定でオフにして No.2 | 画面は出ないが、通知と音は出る。アプリに ST-PERM-FSI の注意が出る | |
| 10 | 正確なアラームの許可がオフ | 設定でオフにしてアプリを開く | アラームの設定と寝室に ST-PERM-EXACT-ALARM の帯が出る。自動モードは「一時停止中」 | |
| 11 | 無操作 | 鳴っても触らない | 10 分で止まり、「アラームを止めました」の通知が出る | |
| 12 | 自動モード中のカーテン | 自動モードをオンにして No.2 | アラームの 10 分前にカーテンが開く。カーテンが失敗してもアラームは鳴る | |

## 記録すること

端末名、Android の版、アプリのビルド、各 No. の結果（OK／NG と、鳴るまでの遅れ秒数）。
